                    化工AI专业版 - 启动说明
══════════════════════════════════════════════════════════════

【第一步：配置API Key】
1. 打开 config.py 文件
2. 找到第8行：DASHSCOPE_API_KEY = 'your-dashscope-api-key-here'
3. 将引号内的内容替换为您的阿里云DashScope API Key
   例如：DASHSCOPE_API_KEY = 'sk-xxxxxxxxxxxxxxxxxxxx'

如何获取API Key：
1. 访问 https://dashscope.console.aliyun.com/
2. 注册/登录阿里云账号
3. 开通DashScope服务
4. 在API Key管理中创建并复制您的API Key

【第二步：启动系统】

▶ Windows用户：
   双击运行 start.bat
   脚本会自动安装依赖并启动系统

▶ Mac/Linux用户：
   打开终端，进入AIGC目录
   执行命令：chmod +x start.sh
   执行命令：./start.sh

【第三步：访问系统】
1. 启动成功后，打开浏览器
2. 访问地址：http://localhost:5000
3. 默认账号：admin
   默认密码：admin123

【系统功能说明】
✓ 智能问答：基于化工知识库的专业问答
✓ 知识库管理：支持上传PDF、Word、Markdown、TXT文件
✓ RAG检索：自动检索相关文档内容
✓ 预装知识库：
  - 聚合工艺操作规程
  - 化工安全作业规范  
  - 设备故障排查手册

【注意事项】
⚠ 首次启动会自动安装依赖包，请耐心等待
⚠ 确保网络连接正常，需要调用阿里云API
⚠ 如需修改端口，请编辑 app.py 最后一行
⚠ 建议使用 Python 3.8 - 3.11 版本

【技术支持】
如遇问题，请检查：
1. Python环境是否正确安装
2. API Key是否正确配置
3. 网络是否能正常访问阿里云
